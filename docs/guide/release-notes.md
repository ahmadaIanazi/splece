# Splece — first public source beta

Splece is a free, local video generator and editor built from the ground up for AI. Plan on a canvas, work with references, compare takes and refine the result on the timeline.

## Included

- Apache-2.0 source with separate trademark and third-party notices.
- Desktop studio, local project/media handling, generation adapters and regression tests.
- Getting started, prompting, provider support and adapter contribution guides.
- Connection onboarding and the Offline/Online control.
- Mapped Venice, xAI, fal.ai, OpenAI, OpenRouter and DeepSeek task integrations; see the provider support table for exact scope.

**iOS and Android are coming soon.** Mobile is in development and is not included as a public download in this release.

## Validation and limits

- Clean dependency installation and production interface build passed.
- 778 regression tests passed, with no paid provider inference.
- Git history and staged source secret scans passed; repository hygiene passed.
- Dependency audit reported no known vulnerabilities at preparation time; this is not a full security audit.
- Direct xAI/Grok live output remains unverified; mocked transport tests are not a live-provider certification.
- Windows beta is unsigned; Linux beta is experimental. The separate FFmpeg binary corresponding-source/build-material review remains unfinished. This source release includes no FFmpeg or installer binaries.

Original code is Apache-2.0. Dependencies and bundled components retain their own licenses. The Splece name and logo are reserved for the official project.
