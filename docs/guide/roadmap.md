# Coming next

## iOS and Android — coming soon

Splece is being built for mobile too. The mobile work is in development, with no public download or committed release date. Desktop/mobile feature parity and project interchange are not promised by this beta. This public repository currently contains the desktop studio.

## Desktop priorities

- Make provider adapters easier to contribute and verify.
- Improve first-run reliability and connection guidance.
- Strengthen editing, playback and recovery across operating systems.
- Expand accessibility and keyboard consistency.
- Complete platform distribution/license review and broader device testing.

These are priorities, not a delivery schedule. Propose a focused change through [Contributing](../../CONTRIBUTING.md).
