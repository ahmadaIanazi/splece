# Splece starter animatics

Original procedural illustrations and motion studies created for this repository.
No competitor media, third-party stock, downloaded footage, or model outputs are included.
They are intentionally illustrative samples, not demonstrations of AI generation quality.

Each template has a JPEG poster, four independent 5-second H.264 clips and a
20-second concatenated preview. Clips are silent, 24 fps, baseline H.264 / yuv420p
with fast-start MP4 metadata. The whole collection is bundled and works offline.

Rebuild with Python + Pillow: `python scripts/build-template-media.py`.
The renderer uses the repository's existing `ffmpeg-static` executable.
