Help with Splece

Support

For iPhone and iPad release availability, visit Splece for iOS. For Mac, Windows and Linux, use the desktop downloads.

How do I install the iOS beta?

Splece has been submitted for App Store review. Public installation is not available yet. If Apple invited you to test, open that invitation on your iPhone or iPad and follow the TestFlight instructions. Installing TestFlight by itself does not grant access to Splece. Public installation options appear on the iOS page when available.

Can I work without a provider?

Yes. No Splece account or API key is required for local planning and editing. Import your media from Photos or Files, arrange your scenes, preview the timeline and export on your device. Online AI features require a supported provider and may use its credits.

My provider will not connect

Open Connections, choose the provider that issued your key and follow its setup steps. Check API access and credits in its dashboard. Enable Online when you intend to verify or use that connection. Select a model that supports the task and inputs you need. Never send support an API key.

My export or generation stopped

For a local export, check free device storage, keep the app open and try a short edit. For an online generation, check the existing job and provider dashboard before submitting again: a delayed result may already have been accepted and billed.

Contact support

Report an issue to the Splece maintainer. Include your device, OS version, app version/build and the steps that reproduce the problem. GitHub issues are public; use a sample project and omit keys, personal files and private screenshots.

TestFlight testers can also use Send Beta Feedback for Splece in TestFlight. For privacy matters requiring a private reply, ask for a private contact without publishing the details. Report a security vulnerability through GitHub’s private security form.
